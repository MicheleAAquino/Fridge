# Fridge 🧊

API REST desenvolvida em Java com Spring Boot para gerenciamento de informações relacionadas a uma geladeira.

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento Backend, criação de APIs REST, persistência de dados e utilização do Spring Boot.

## 🚀 Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- H2 Database
- Lombok
- Maven

## 📚 Conceitos praticados

- Desenvolvimento de API REST
- Spring Boot
- Injeção de dependências
- Persistência de dados com JPA
- Banco de dados H2
- Mapeamento objeto-relacional (ORM)
- Arquitetura de aplicações Backend
- Maven para gerenciamento de dependências
